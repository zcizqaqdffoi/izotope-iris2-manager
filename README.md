## Overview

iZotope Iris 2 Spectral Manager provides a dedicated preset and sample library browser for iZotope Iris 2, organizing factory and user presets by category and sound character, enabling quick swap of the four spectral layers, and managing user sample pools imported into Iris 2 for spectral synthesis use.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Iris 2 Spectral Manager** delivers the features you need in a clean, intuitive package.

> Official website: [izotope.com](https://izotope.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Preset Browser** | Browse and filter all Iris 2 presets by category and sound character |
| **Layer Management** | Quickly assign different samples to each of the four spectral layers |
| **Sample Pool** | Organize user-imported samples into named pools for Iris 2 use |
| **Quick Preview** | Audition presets from the browser before loading them into Iris 2 |
